# 🍎 Apple Inc. Stock Market Analysis Dashboard

## 📌 Project Overview

The **Apple Inc. Stock Market Analysis Dashboard** is an interactive Business Intelligence project developed using Microsoft Power BI.

This project analyzes Apple's stock market performance using the latest 100 days of historical stock data collected through a REST API.

The dashboard transforms raw stock market data into meaningful business insights through interactive visualizations, KPIs, and trend analysis.

## 🎯 Project Objectives

- Analyze Apple's stock market performance.
- Track daily and monthly stock price movements.
- Monitor trading volume trends.
- Identify highest and lowest stock prices.
- Support data-driven decision-making through interactive dashboards.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- REST API Integration
- Data Modeling
- Data Visualization

## 📊 Key Performance Indicators (KPIs)

- Total Trading Volume
- Highest Stock Price
- Lowest Stock Price
- Latest Opening Price
- Latest Closing Price
- Latest Trading Date

## 📈 Dashboard Features

- Interactive Date Range Slicer
- Monthly Average Closing Price Analysis
- Opening vs Closing Price Trends
- High vs Low Stock Price Comparison
- Daily Trading Volume Analysis
- Monthly Stock Performance Summary

## 🔄 Data Processing Workflow

1. Extract stock market data using REST API.
2. Transform and clean data using Power Query.
3. Create data models and relationships.
4. Develop calculated measures using DAX.
5. Design interactive dashboards and visualizations.
6. Analyze stock market trends and performance.

## 💡 Key Insights

- Monthly stock price movements can be compared.
- Opening and closing price trends help evaluate daily performance.
- Highest and lowest prices highlight market fluctuations.
- Trading volume helps understand daily market activity.
- Date filters enable analysis of selected periods.
